# 平台展示规则与AI生成指南

本文件供阶段7（商品展示素材）引用。平台规则可能随时变更，使用前建议搜索确认最新规则。

---

## 一、平台展示规则速查

| 平台 | 图片规则 | 视频规则 | 流量倾斜 |
|------|---------|---------|---------|
| 闲鱼 | 最多9张，首图决定点击率 | 支持短视频但不是主流 | 图片为主，首图有文字说明效果好 |
| 淘宝 | 主图5张，详情页无限制 | 主图视频15-60秒，有尺寸要求 | 有主图视频的商品权重更高 |
| 小红书 | 图文笔记最多18张 | 视频笔记可达15分钟 | 视频流量 > 图片流量，封面决定一切 |
| 抖音 | 挂车图片简单 | 短视频是核心，15秒-3分钟 | 没有视频基本没有流量 |
| 微信/私域 | 朋友圈9图，公众号无限制 | 视频号可发 | 视频号有流量扶持 |

## 二、图片制作指南

### 图片类型选择

| 图片类型 | 适合场景 | 怎么做 |
|---------|---------|--------|
| 产品截图 | 软件安装成功界面、IDE运行结果 | 截图 + 箭头标注关键信息 |
| 对比图 | 安装前vs安装后、问题vs解决 | 左右或上下对比，视觉冲击 |
| 流程图 | 服务步骤展示 | 用箭头连接各步骤，简单清晰 |
| 文字海报 | 核心卖点、套餐价格 | 大字号 + emoji + 简洁信息 |
| 案例展示 | 真实客户反馈、好评截图 | 马赛克隐私信息后展示 |

### AI生成提示词模板

**商品主图（首图，决定点击率）：**
> 请帮我生成一张商品主图，商品是[商品名称]，核心卖点是[卖点]。风格[专业/简洁/温暖]，需要包含的文字信息：[文字内容]。尺寸[平台要求的尺寸]，背景色[颜色]。文字要清晰可读，整体看起来[专业/靠谱/亲切]。

**对比图/流程图：**
> 请帮我生成一张[对比图/流程图]，展示[内容]。左侧/上方是[状态A]，右侧/下方是[状态B]。用箭头连接，风格简洁专业。

**推荐工具**：GPT-4o、Kimi、通义千问、可灵（图片生成）。工具更新快，使用时搜索最新可用工具。

## 三、视频制作指南

### 视频类型选择

| 视频类型 | 适合场景 | 怎么做 |
|---------|---------|--------|
| 屏录操作 | 软件安装、环境搭建 | 录屏+语音讲解，展示全过程 |
| 真人讲解 | 咨询、教学、老年受众 | 手机前置摄像头，自然说话 |
| 产品展示 | 实物商品 | 拍产品使用过程，展示细节 |
| 图文轮播 | 设计作品、对比效果 | 多张图片合成15-30秒短视频 |

### 老年受众视频特别注意事项

| 要点 | 怎么做 | 为什么 |
|------|--------|-------|
| 语速慢 | 比正常说话慢1.5倍 | 听得清、跟得上 |
| 字号大 | 视频内文字至少占画面1/4 | 看得见 |
| 说人话 | 不用技术术语，用生活化语言 | 听得懂 |
| 真人出镜 | 最好是真人面对镜头说话 | 更信任"活人" |
| 重复重点 | 关键信息说两遍 | 记得住 |
| 时长短 | 控制在60秒以内 | 不走神 |

### AI生成视频提示词模板

**屏录类（用AI图片转视频）：**
> 请生成一段展示[软件/产品]使用过程的短视频，时长[X]秒。画面从[起始画面]过渡到[成功画面]，节奏平稳，重点展示[关键步骤]。

**真人讲解类（用数字人或图片转视频）：**
> 请生成一段[X]秒的产品介绍视频，面向[受众类型]，语速[正常/偏慢]，风格[专业/亲切/温暖]。需要传递的信息：[信息要点]。

**推荐工具**：即梦（字节）、可灵（快手）、Runway、HeyGen（数字人）、剪映（编辑）。工具更新快，使用时搜索最新可用工具。
