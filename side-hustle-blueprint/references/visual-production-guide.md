# 视觉素材生产指南

本文件供阶段7（商品展示素材）引用。定义技能应该帮用户生成哪些文字文件，以及推荐哪些工具来生成视觉素材。

---

## 核心原则

**视觉素材的本质不是展示你多厉害，而是让客户0.5秒内产生"这个人懂我的问题"。**

首图/视频开头 = 客户需求的镜像，不是你能力的展示。

| 客户需求性质 | 首图/开头策略 | 做什么 |
|------------|------------|-------|
| 止痛药（急） | 痛点场景 | 展示他正在经历的痛苦（报错弹窗、蓝屏、崩溃） |
| 偏止痛药 | 结果展示 | 展示你能帮他达到的效果（装好后打开的界面） |
| 维生素 | 信任信号 | "已帮200+人"、好评截图、真实案例 |

## 一、图片工作流

### 1.1 图片简报（技能帮用户生成）

对每张需要生成的图片，输出以下简报：

```
图片编号：1 / 共X张
用途：[首图/详情图/对比图/好评截图/价格海报]
核心信息：[图片上要传递什么信息？文字写什么？]
画面描述：[主要画面是什么？]
风格：[专业/简洁/温暖/科技感]
尺寸：[平台要求的尺寸]
目标受众：[学生/上班族/老年人/技术人员]
```

### 1.2 AI图片生成提示词（技能帮用户生成）

根据简报，生成可以直接复制给AI图片工具的提示词：

**商品主图提示词模板：**
```
[图片类型] + [主体内容] + [文字及位置] + [风格] + [尺寸] + [排除项]
```

**产品实拍增强模板：**
```
将这张[产品类型]的照片进行美化处理，背景改为[纯白/渐变色/场景化]，
增强[光线/清晰度/质感]，保持产品本身不变，风格[专业/简洁/高端]
```

### 1.3 后处理说明

AI生成的图片通常需要后处理才能上架：

| 步骤 | 说明 |
|------|------|
| 加文字 | AI生成的图片上文字经常乱码，用编辑工具后期加上 |
| 裁剪尺寸 | 适配平台要求的比例 |
| 拼图排版 | 多张图拼成对比图/流程图 |
| 加水印 | 防盗图（可选） |

### 1.4 图片场景选择

| 场景 | 做法 | 是否需要AI生成 |
|------|------|--------------|
| 有实体产品 | 直接拍照 → 用AI增强/换背景 | 部分需要 |
| 软件安装/技术类 | 截图 + 箭头标注 | 不需要 |
| 设计作品展示 | 导出作品图 | 不需要 |
| 对比图（前vs后） | 两张截图拼接 | 不需要 |
| 文字海报/价格卡 | 需要设计感 | 需要AI生成 |

**不是所有图片都需要AI生成。** 很多场景直接截图/拍照就够了。

## 二、视频工作流

### 2.1 脚本（技能帮用户生成）

输出格式：

```
视频目标：[这个视频要达到什么效果]
目标受众：[给谁看]
总时长：[X秒]

--- 脚本内容 ---

[0-3秒] 痛点场景
画面：[描述]
字幕/旁白：[文字]

[3-10秒] 解决方案
画面：[描述]
字幕/旁白：[文字]

[10-20秒] 过程展示
画面：[描述]
字幕/旁白：[文字]

[20-25秒] 结果展示
画面：[描述]
字幕/旁白：[文字]

[25-30秒] 行动引导
画面：[描述]
字幕/旁白：[文字]
```

### 2.2 分镜表（技能帮用户生成）

把脚本拆成逐帧分镜：

| # | 时长 | 画面描述 | 旁白/字幕 | AI生图提示词 |
|---|------|---------|----------|------------|
| 1 | X秒 | [画面内容] | [文字内容] | [给图片生成模型的提示词] |
| 2 | X秒 | ... | ... | ... |
| ... | ... | ... | ... | ... |

### 2.3 分镜衔接提示词（技能帮用户生成）

把分镜图连成视频时，需要告诉视频生成模型"怎么从一个画面过渡到下一个"：

```
从分镜[N]过渡到分镜[N+1]：
- 画面变化：[从什么画面到什么画面]
- 运动方式：[推近/拉远/平移/淡入淡出]
- 节奏：[快/慢/自然过渡]
```

### 2.4 老年受众视频注意事项

| 要点 | 怎么做 |
|------|--------|
| 语速慢 | 比正常说话慢1.5倍 |
| 字号大 | 视频内文字至少占画面1/4 |
| 说人话 | 不用技术术语 |
| 真人出镜 | 面对镜头说话 |
| 重复重点 | 关键信息说两遍 |
| 时长短 | 控制在60秒以内 |

## 三、工具推荐

> 工具更新很快，以下为当前推荐。使用时请搜索确认最新可用工具。

### 图片生成

| 工具 | 费用 | 特点 | 适合谁 |
|------|------|------|--------|
| 即梦 | 付费 | 效果最好，细节丰富 | 追求高质量商品图 |
| 豆包 | 免费 | 满足基本需求 | 起步阶段、简单图片 |
| 产品实拍 | 0 | 最真实可信 | 有实体产品的卖家 |

**大电商/正规店铺：建议实拍，不用AI生图。** 拍完可以用AI工具做背景替换、光线增强等修饰。

### 视频生成

| 工具 | 费用 | 特点 |
|------|------|------|
| oiioii | 按需 | 视频生成 |
| Gemini系列 | 按需 | 多模态，可生成视频 |
| 剪映 | 免费 | 视频编辑、加字幕、加配音 |

### 编辑工具

| 工具 | 用途 |
|------|------|
| 剪映 | 视频剪辑、加字幕、加音乐、加转场 |
| 美图秀秀 | 图片加文字、拼图、水印 |
| Canva | 海报设计、图片排版 |
