# 副业蓝图（side-hustle-blueprint）

帮用户从零到一规划并上线一个服务型副业。输出一套可直接使用的文件。

## 怎么用这个技能

8个阶段，按顺序走，但**用户可以跳过任何阶段**。如果用户说"我只要帮我写文案"，就从阶段6开始。

每个阶段结束时和用户确认再往下走，不要一口气全写完。

---

## 阶段1：摸底

了解用户的情况。问以下问题，答不全没关系，后续补充。

### 必问

| 问题 | 为什么问 |
|------|---------|
| 你会什么？ | 确定可卖的能力 |
| 每天花多少时间？什么时候有空？ | 确定接单上限和时间窗口 |
| 目标月收入？ | 确定定价策略 |
| 有什么不碰的事？ | 道德/法律边界 |

### 选问（有时间再问）

- 你用什么工具能快速产出？
- 有作品/案例吗？

### 输出

整理一份用户画像摘要让用户确认。

---

## 阶段2：身份匹配与商业可行性分析

**这是最关键的阶段。** 先搞清楚"你是谁"，再决定"去哪卖"和"值不值得做"。

### 2.1 身份画像

问以下问题，确定用户的经营身份：

| 问题 | 为什么问 |
|------|---------|
| 你是什么身份？（学生/上班族/自由职业/有公司） | 决定能开什么类型的店 |
| 有没有营业执照？ | 有 → 淘宝/拼多多正式开店；没有 → 闲鱼/小红书零门槛 |
| 有运营渠道吗？具体是什么？（直播/公众号/社群/粉丝量） | 决定获客方式，有渠道 = 有免费流量 |
| 愿意投入多少成本？（0/几百/几千） | 决定推广策略和平台选择 |

### 2.2 平台匹配

根据身份画像，帮用户匹配最佳平台。**不要替用户选，给分析让用户决定。**

#### 平台决策树

```
有营业执照？
  ├─ 是 → 淘宝/拼多多（正式开店，押金1000-2000）
  │        优势：搜索流量大、可投广告、店铺权重积累
  │        劣势：有押金、有手续费、要维护店铺评分
  │
  └─ 否 → 闲鱼（零门槛，无押金）
           优势：零成本、上手快、闲鱼搜索有自然流量
           劣势：单量天花板低、平台抽手续费、不好做品牌

有内容能力（直播/短视频/写作）？
  ├─ 是 → 小红书/B站/抖音（内容引流 → 私域/闲鱼成交）
  │        优势：免费流量、长期积累、信任感强
  │        劣势：起号慢、需要持续产出内容
  │
  └─ 否 → 纯靠平台搜索流量（最被动但最省力）

有技术社区影响力？
  ├─ 是 → GitHub/V2EX/掘金/知乎（精准客户，转化率高）
  └─ 否 → 跳过
```

#### 多平台组合建议

给用户推荐1-2个平台的组合，说明理由：

| 组合 | 适合谁 | 优势 |
|------|-------|------|
| 闲鱼单平台 | 零基础起步、时间少 | 最简单，0成本 |
| 闲鱼 + 小红书 | 有内容能力、愿意做内容 | 内容引流+闲鱼成交 |
| 淘宝单店铺 | 有执照、想做长期 | 正规化，可投流 |
| 私域（微信/社群） | 有现成客群 | 复购率高，零平台费 |

### 2.3 需求性质判断：止痛药还是维生素？

**在算可行性之前，先判断你要卖的东西属于哪种需求。** 这直接决定了你的获客难度和定价空间。

#### 什么是止痛药？什么是维生素？

| | 🔴 止痛药 | 🟢 维生素 |
|--|----------|----------|
| **定义** | 客户现在就痛，必须马上解决 | 锦上添花，不急 |
| **客户行为** | 主动搜索、马上付钱、不太比价 | 犹豫、比价、拖延、可能不买 |
| **定价空间** | 高（急了不差钱） | 低（慢慢选，选最便宜的） |
| **获客难度** | 低（客户自己找你） | 高（你要说服他买） |
| **例子** | "毕设明天交，PS装不上！" | "我想学PS，以后可能用得上" |
| **例子** | "电脑蓝屏了打不开！" | "想给电脑做个优化清理" |
| **例子** | "论文今晚要交，格式全乱了！" | "想学一下Word排版技巧" |

#### 判断方法

问用户一个问题：

> **你的客户如果不找你，会怎样？**

| 回答 | 类型 | 结论 |
|------|------|------|
| "他搞不定，会急死" | 止痛药 | ✅ 优先做这个，起步最容易 |
| "他可以自己慢慢研究，就是费时间" | 偏止痛药 | ✅ 可以做，强调"省时间" |
| "他可能过几天再说，不急" | 维生素 | ⚠️ 获客难，不建议起步阶段做 |
| "他可能不需要，除非看到觉得有用" | 纯维生素 | ❌ 起步阶段别碰 |

#### 起步建议

**副业起步，优先选止痛药。** 原因：

1. **客户主动找你** — 不用花精力推销，搜索流量就够了
2. **转化率高** — 痛着呢，看到能解决就下单
3. **价格不敏感** — 急了不太比价，你能定更高的价
4. **口碑容易建立** — 解决了别人的燃眉之急，好评自然来

如果用户想做的事是维生素，帮他想办法转成止痛药：
- "学PS" → "毕设海报今晚要交，PS还装不上？我帮你搞定"
- "电脑优化" → "电脑卡到影响工作了？远程帮你清理提速"

### 2.4 可行性快算

用这个公式帮用户算一下这生意值不值得做：

```
你的时间价值 = 目标月收入 ÷ 月可用小时数 = 你的目标时薪
单均耗时 = 完成一单平均要多久（分钟/小时）
单均收入 = 市场参考价 × (1 - 平台手续费率)
单均利润 = 单均收入 - 单均成本（工具/推广等）
实际时薪 = 单均利润 ÷ 单均耗时

实际时薪 ≥ 目标时薪？ → 值得做
实际时薪 < 目标时薪？ → 需要调整（提价/换品类/提高效率）
```

把计算过程和结果展示给用户，让用户自己判断。

### 输出

- 身份画像摘要
- 推荐平台 + 理由
- 需求性质判断（止痛药/维生素 + 建议）
- 可行性计算结果
- 明确结论：**这生意值不值得做，为什么**

让用户确认后再往下走。

## 阶段3：市场调研（双重验证）

帮用户调研同类服务的市场定价和竞争环境。

### 3.1 搜竞品定价

在闲鱼/淘宝搜索相关关键词，每个关键词记录：标题、价格、销量、描述要点。

### 3.2 竞品健康度检查

不只看价格，还要看竞品**活得怎么样**：

| 检查项 | 怎么看 | 说明什么 |
|--------|-------|---------|
| 销量趋势 | 看月销vs总销 | 月销高=持续有需求；总销高但月销低=过气了 |
| 评价真实性 | 看追评和差评 | 全是好评无追评=可能刷的；有差评但商家认真回复=真实经营 |
| 价格分布 | 低价/中价/高价各多少家 | 只剩低价=卷完了，别进去 |
| 卖家专业度 | 看描述质量、客服话术 | 都很糙=市场还没人做好，你的机会 |
| 复购率 | 看评价里有没有"又来了" | 有复购=客户粘性好，值得做 |

### 3.3 受众群体推断（新增）

**从竞品数据中推断客户是谁，不靠猜。**

在搜竞品和看评价时，同步收集以下信息：

| 数据来源 | 看什么 | 能推断什么 |
|---------|--------|-----------|
| 竞品标题/描述 | 写了"学生党""打工人""小白" | 卖家已经帮你定位了受众 |
| 买家评价语气 | "谢谢学长""救了毕设""阿姨看不懂" | 直接告诉你买家是谁 |
| 搜索关键词 | "毕设""论文""考研"→学生；"办公""效率"→上班族 | 搜索词暴露需求场景 |
| 评价时间分布 | 集中在深夜→学生/加班族；白天均匀→全人群 | 作息反映身份 |
| 追问内容 | "会不会弄丢数据？""装完能用多久？" | 担忧点反映技术水平 |

把这些数据汇总，给用户一个受众判断结论让他确认：

```
根据竞品评价和搜索关键词分析：
- 你的客户大概率是：学生 / 上班族 / 中老年 / 技术人员 / 全人群
- 判断依据：[列出具体数据]
- 这个群体的特点是：[消费习惯、沟通偏好、展示偏好]
```

### 定价建议

基于竞品数据给出：
- 市场最低价 / 最高价 / 均价
- **竞品健康度结论**：这个市场是蓝海还是红海？还有没有空间？
- 建议定价 + 理由
- 问用户：走低价走量，还是高价差异化？

### 找不到竞品时

如果搜索无结果，用类似服务的定价做参考，或者按阶段2的可行性快算来确定底价。

## 阶段4：设计服务套餐

### 4.1 服务分层

帮用户把服务分成：
- **引流品**（低价，让客户先体验）
- **主打品**（核心收入来源）
- **利润品**（高单价，偶尔来一单就很赚）

每层定义：套餐名、包含什么、不包含什么、定价、耗时、目标客户。

### 4.2 护城河思考

设计套餐时，帮用户想清楚**凭什么客户选你不选别人**：

| 护城河类型 | 怎么做 | 例子 |
|-----------|--------|------|
| 服务差异化 | 别人不愿意做的你做 | "装不上全退"+"30天售后" |
| 速度优势 | 比别人快 | "下单后30分钟内响应" |
| 信任优势 | 用真实身份/案例背书 | 展示真实作品、用真名、有固定职业 |
| 细分市场 | 做别人不做的细分 | 专门做Mac用户 / 专门做M1芯片 / 专门做学生毕设 |
| 组合优势 | 把多个能力打包 | "装软件+教基础操作"一站式 |

给用户分析：基于他的能力和资源，哪条护城河最容易建。

### 4.3 信任体系设计

**护城河解决"凭什么选你"，信任体系解决"凭什么信你"。** 两者缺一不可。

客户在平台搜索，看到10个卖家，凭什么点你的？点进来凭什么下单？这就是信任的问题。

#### 信任的四个来源

**① 外观信任 — 第一眼觉得你靠谱**

| 要素 | 做什么 | 为什么 |
|------|--------|-------|
| 头像 | 用真人照片或专业logo | 体现真实性和专业感 |
| 昵称 | 体现你能做什么，如"小王｜远程装软件" | 一眼知道你是干嘛的 |
| 商品图 | 干净、清晰、有文字说明 | 体现用心程度 |
| 文案排版 | 有结构、有emoji分隔、不乱 | 体现专业态度 |

**② 能力信任 — 相信你真的能做**

| 要素 | 做什么 | 为什么 |
|------|--------|-------|
| 作品展示 | 把做过的案例截图放上去 | 眼见为实 |
| 数字背书 | "已帮X人成功安装"、"做这个3年了" | 数字给人安全感 |
| 细节展示 | 描述中写出具体步骤和能解决的问题 | 懂行的人才能说出细节 |
| 特殊认证 | 如果有相关证书/学历可以提 | 增加权威感 |

**③ 保障信任 — 降低客户的决策风险**

| 要素 | 做什么 | 为什么 |
|------|--------|-------|
| 退款承诺 | "装不上全退"、"不满意全额退款" | 客户零风险，才敢下单 |
| 平台担保 | 强调走平台交易，有支付宝担保 | 官方背书比你说什么都有用 |
| 过程透明 | "全程远程，你可以看着操作" | 客户看得见=放心 |
| 售后承诺 | "30天内出问题免费处理" | 证明你不会收钱就跑 |

**④ 口碑信任 — 别人说你好，比自己说有用**

| 阶段 | 怎么做 | 具体动作 |
|------|--------|---------|
| 前3单 | 主动要好评 | 完成后说"满意的话帮忙点个好评🙏，对我真的很重要" |
| 有了5+好评 | 在描述中引用好评 | 截图真实好评放在商品描述里 |
| 有了20+好评 | 做回头客引导 | "老客户9折"+定期更新商品刷新排名 |

#### 帮用户执行的步骤

根据用户的实际情况，帮他制定信任建设计划：

1. **上架前**：确定头像、昵称、商品图的风格
2. **写文案时**：把能力信任和保障信任的要素融入商品描述
3. **前3单**：重点关注好评获取，哪怕利润低一点
4. **稳定后**：开始引用好评、做复购引导

### 定规则

提供选项让用户选，不要替用户决定：

| 规则 | 选项举例 |
|------|---------|
| 退款 | 不退 / 装不上退 / 无条件退 |
| 续费 | 原价 / 有折扣 |
| 售后期 | 无 / X天 |
| 答疑范围 | 只管安装 / 包使用 / 包一切 |
| 每天上限 | 不限 / X单 |

## 阶段5：客户筛选

### 定义三类人

| 类型 | 处理 |
|------|------|
| ✅ 核心客户 | 接单 |
| ⚠️ 看情况 | 有条件接 |
| ❌ 不服务 | 怎么拒绝 + 给什么替代 |

### 写筛选话术

2-3个快速判断问题，30秒内决定接不接。

### 准备甩人素材

教程链接或文档，给不符合条件的客户自己学。

---

## 阶段6：写平台文案

根据阶段2确定的平台，为每个商品写对应的文案。

### 标题（3-4个选项，覆盖搜索词）
- 开头用服务名/工具名
- 中间写核心功能
- 结尾写适用条件

### 商品描述（直接复制粘贴用）
- 先说痛点 → 再说服务 → 再说价格 → 最后说规则
- 用 emoji 分隔区块
- **融入信任要素**：展示能力（已帮X人）、提供保障（装不上退）、过程透明（远程看着操作）

### 聊天话术（每个场景一段）
- 下单后确认 / 开始前准备 / 完成后引导 / 超范围怎么说 / 续费怎么引
- **完成后引导必须包含好评引导话术**

### 不同平台的文案差异

| 平台 | 文案风格 | 注意事项 |
|------|---------|---------|
| 闲鱼 | 口语化、接地气、个人感强 | 强调"个人服务"+"真实靠谱" |
| 淘宝 | 专业、规范、店铺感 | 需要更正式的描述和清晰的SKU |
| 小红书 | 故事感、体验感、带图 | 标题要有"人味"，不是纯卖货 |

---

## 阶段7：商品展示素材

文案写完了，接下来就是**客户第一眼看到的东西：图片或视频**。

**不替用户决定用图还是用视频，而是从已有数据中推断，给用户建议让他确认。**

### 7.1 从已有数据推断受众群体

不额外问用户，直接从前面的数据中汇总：

| 数据 | 从哪来 | 怎么用 |
|------|-------|--------|
| 竞品评价语气 | 阶段3.3 | 看买家是学生/上班族/中老年 |
| 竞品描述定位 | 阶段3 | 卖家写"学生党""打工人"就是受众 |
| 搜索关键词 | 阶段3 | "毕设"→学生，"办公"→上班族 |
| 产品本身性质 | 阶段1 | 软件安装→年轻人，手机清理→可能中老年 |
| 平台用户画像 | 阶段2 | 闲鱼→偏年轻，淘宝→全年龄，小红书→偏女性 |

综合这些数据，给用户一个受众判断结论让他确认。

### 7.2 展示形式决策：图片还是视频？

根据受众 + 平台 + 产品，三个维度交叉决定：

#### 维度一：受众决定偏好

| 受众群体 | 展示偏好 | 原因 |
|---------|---------|------|
| 老年人 | **视频优先** | 看不清小字，更信"真人说话"，不太会放大看图 |
| 学生 | 图片优先 | 时间紧，扫一眼就要判断，不爱看长视频 |
| 上班族 | 图片 ≥ 视频 | 碎片时间看，静音环境多，图更方便 |
| 技术人员 | 图片优先 | 习惯看截图/文档，觉得视频太慢 |
| 女性消费者 | 图文 + 视频 | 注重审美和细节，精美的图+使用场景视频 |

#### 维度二：平台决定规则和流量

**用户大概率不知道平台规则，所以这一步必须帮用户查清楚。**

搜索该平台最新的商品展示规则，重点关注：

| 平台 | 图片规则 | 视频规则 | 流量倾斜 |
|------|---------|---------|---------|
| 闲鱼 | 最多9张，首图决定点击率 | 支持短视频但不是主流 | 图片为主，首图有文字说明效果好 |
| 淘宝 | 主图5张，详情页无限制 | 主图视频15-60秒，有尺寸要求 | 有主图视频的商品权重更高 |
| 小红书 | 图文笔记最多18张 | 视频笔记可达15分钟 | 视频流量 > 图片流量，封面决定一切 |
| 抖音 | 挂车图片简单 | 短视频是核心，15秒-3分钟 | 没有视频基本没有流量 |
| 微信/私域 | 朋友圈9图，公众号无限制 | 视频号可发 | 视频号有流量扶持 |

**如果规则有不确定的，搜索该平台最新的官方规则确认，不要用过时信息。**

#### 维度三：产品决定展示内容

| 卖什么 | 最佳展示 | 为什么 |
|--------|---------|--------|
| 软件安装调试 | 屏录视频 + 安装前后对比图 | 客户要看到"过程"才放心 |
| 设计/剪辑作品 | 作品集图片 | 视觉冲击力强，一眼判断水平 |

| 咨询/教学 | 真人讲解视频 | 客户要感受你的专业度和沟通风格 |
| 编程环境搭建 | 终端/IDE截图 + 跑通结果 | 技术人看截图就够了 |

## 核心原则

1. **每个阶段确认后再往下走**
2. **用户说不做就不做** — 不要加用户没要求的东西
3. **用用户自己的原话** — 定价、规则等用用户说的措辞，不要改写
4. **做减法** — 用户说"不用那么复杂"就简化
5. **信息免费，时间付费** — 告诉方向免费，动手操作才收费
6. **帮人省时间不帮人省脑子** — 不替用户做本该自己学的
7. **先算账再动手** — 阶段2的可行性快算做完了，确认"值得做"再往下走，不值得就诚实告诉用户
8. **身份先行，平台匹配** — 先搞清楚用户是谁、有什么资源，再决定去哪卖
9. **止痛药优先** — 起步阶段优先选择客户有紧急痛点的服务，获客最容易
10. **信任是成交的最后一公里** — 需求匹配了但客户不信你，交易不会发生。每个阶段都要融入信任建设
11. **数据驱动受众判断** — 不猜测客户是谁，从竞品评价、搜索词、产品性质等真实数据中推断
