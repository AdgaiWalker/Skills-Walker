# 小红书图文笔记生成器

帮用户把经验、工具、项目、观点变成一篇能被看到的小红书笔记。

## 核心原则

**先调查再写**：不凭空编造效果、数据或背景。素材从对话、README、截图、仓库中找。

**标题俗，结尾升**：标题用最直白的好处钩人进来（省时间、避坑、搞定了），正文最后用认知转变或判断收住。俗是为了让人点进来，升是为了让人记住。

**观点优先**：文章能被人记住的，不是事实，是观点。事实是"微信数据 8GB"，观点是"想不起来的东西，就是电脑在帮你减负"。如果用户没有明确观点，帮用户提炼。

**人话**：像创作者本人说话，不像品牌号、不像说明书、不像 SEO 堆砌。

## 执行流程

### 1. 调查素材

从对话和用户提供的材料中收集：

- 这篇笔记要发什么？（工具、经验、观点、教程、踩坑记录）
- 有没有截图、仓库链接、README、实际效果数据
- 用户的真实动机（为什么做这件事）
- 目标读者是谁（普通人、开发者、特定群体）
- 有没有核心观点（用户想表达的判断）

如果素材不够，先补最小必要信息，再写。

### 2. 确定文章结构

每篇小红书笔记由四部分组成：

**标题** — 一个直白的好处或一个具体的数字，让人想点进来
**正文** — 问题/背景 → 做了什么 → 怎么用 → 转折/收获
**配图建议** — 小红书是图片驱动的，每篇文章都要给配图方案
**标签** — 5-8 个标签，覆盖品类词和场景词

### 3. 判断有没有核心观点

观点 = 一个有人可能说"我不这么认为"的判断。

| 内容 | 类型 | 为什么 |
|------|------|--------|
| 微信聊天记录藏在 Documents 下面，8GB | 事实 | 谁看都是 8GB |
| AI 帮我省了几个小时 | 事实 | 你的体验 |
| 想得起来的才重要，想不起来的说明你不需要 | 观点 | 有人会说"不对" |

**如果用户有观点**：放在正文最后 1-2 段，用转折引出（"不过我发现，XX 反而不是最重要的收获"）。
**如果用户没有观点**：从素材中提炼一个，告诉用户"我提炼了一个观点，你看是不是你想说的"。

### 4. 写标题

标题规则：

- 用最直白的好处或最具体的数字
- 不要用模糊的感叹（"太绝了！""收藏！"）
- 控制在 20 字以内
- 可以给出 2-3 个备选让用户挑

好的标题：`AI 帮我重装系统，以前一下午，现在半小时`
不好的标题：`重装系统必备！AI 工具推荐！收藏！`

### 5. 写正文

正文节奏：

```
钩子（痛点场景或具体数字）
    ↓
做了什么（工具/方法/步骤）
    ↓
怎么用（简短的使用方式）
    ↓
转折（"不过我发现，XX 不是最重要的"）
    ↓
核心观点（认知层面的收获）
```

写正文时的注意：

- 用第一人称，像跟朋友说话
- 分段用空行，不要大段文字墙
- 关键信息可以加粗，但不要每段都加粗
- 先说"为什么做"，再说"做了什么"
- 数据要真实，不要编

### 6. 配图建议

小红书笔记至少 3 张图。给出每张图的内容和用途：

| 张数 | 内容建议 | 作用 |
|------|----------|------|
| 封面 | 最有冲击力的画面 | 让人停下来 |
| 中间 | 过程截图、数据、对比 | 证明真实性 |
| 末尾 | 结果或总结 | 强化记忆 |

配图建议要具体：告诉用户截什么、突出什么，不要只说"配一张好看的图"。

### 7. 标签

给 5-8 个标签，分两类：

- **品类词**：平台内搜索量大的词（如 #AI工具、#重装系统）
- **场景词**：具体使用场景（如 #Windows、#程序员日常）

### 8. 自评

写完后自检：

- 标题够不够直白，能不能让人想点进来
- 正文有没有节奏感（不是平铺直叙的信息列表）
- 有没有核心观点（不是只有事实和描述）
- 语气像不像人在说话（不像说明书或营销号）
- 配图建议够不够具体
- 有没有编造数据或效果

## 输出格式

默认输出：

```markdown
# [标题]

[正文]

---

[配图建议表格]

#标签1 #标签2 #标签3 ...
```

如果用户需要，额外给出：
- 标题备选（2-3 个）
- 短版（只保留核心，适合配单张图）

## 与 X 推文的区别

如果用户同时有 X 推文需求，应该用 `qiuzhi-x-post-generator` skill。

两个平台的区别：

| | 小红书 | X/Twitter |
|---|---|---|
| 篇幅 | 可以写长 | 主帖要短 |
| 图片 | 必须，3张起 | 可选 |
| 标签 | 重要，影响推荐 | 不重要 |
| 节奏 | 标题钩人 → 正文展开 → 观点收尾 | 主帖钩人 → 跟帖展开 |
| 语气 | 可以更口语化 | 更克制 |
